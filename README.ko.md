# 웰니스 개호식품 · Soft Care Food

씹기·삼킴이 어려운 어르신과 이를 돌보는 간병인을 위한 **연화식(부드러운 케어식)** 온라인 스토어
및 정기구독 **데모** 웹앱입니다.

**English: [README.md](README.md)**

**라이브 데모: https://clsoftlab-lang.github.io/soft-care-food/**

> ⚠️ **건강 안내.** 본 서비스는 **의료·영양 처방이 아닙니다.** 질환을 진단·치료·관리하지 않으며,
> 연화 단계와 추천은 참고용 예시입니다. **삼킴장애(연하곤란)**나 기타 질환이 있는 경우 식단 변경 전
> 반드시 의사·언어재활사·영양사 등 전문가와 상담하세요.

## 무엇인가요

빌드 과정이 없는 순수 클라이언트(네이티브 ES 모듈) 커머스 데모입니다.

- **제품 카탈로그** — 가상의 케어식 33종. 부드러움 단계(1~4), 영양목적(고단백·저염·삼킴보조),
  식사종류 필터 + 검색 + 정렬(가격·단백질·나트륨·평점).
- **제품 상세** — 연화 단계 시각화, 영양성분, 원재료, 알레르기, 데우는 법, 리뷰.
- **정기구독 플랜** — 주간/월간 플랜, 식단 구성 미리보기, 구독 시작/해지(모의).
- **장바구니 + 모의결제** — 수량 조절, 무료배송 기준, 가짜 결제 완료.
- **어르신 맞춤 설문** — 씹기/삼킴 수준·질환·알레르기·목표 → 추천 엔진이 이유와 함께 식단 추천.
- **찜(위시리스트)**, **큰 글씨 옵션(접근성)**.
- 모바일 우선 반응형, `prefers-color-scheme` 라이트/다크, 한국어 UI, 인라인 SVG 아트만 사용.

## 추천 엔진 동작 방식

`modules/recommend.js` 는 DOM·저장소에 의존하지 않는 **순수·결정론적** 엔진이며 `check.mjs`에서
단위 테스트합니다.

1. **목표 연화 단계** = `max(씹기, 삼킴)`을 1~4단계로 매핑(어려울수록 더 부드럽게).
2. **알레르기 하드 필터** — 선택한 알레르겐이 든 상품은 완전히 제외.
3. **연화 단계 점수** — 목표 이상으로 부드러운 상품은 고득점, 정확히 일치가 최고점, 더 단단하면 감점.
4. **삼킴 곤란**(삼킴 ≥ 3)이면 삼킴보조 상품 가점.
5. **질환**(고혈압/신장질환/당뇨)은 저나트륨 가점, 근감소/회복기·고단백 목표는 단백질 가점.
6. 점수순 정렬 후 근거(reasons)와 함께 반환.

## 로컬 실행

의존성·빌드 없음. ES 모듈은 `file://`이 아닌 `http://`가 필요합니다.

```bash
python -m http.server 9001
# http://localhost:9001 접속
```

```bash
node check.mjs   # JSON 파싱, JS node --check, index.html 컨테이너, 추천 엔진 단위 테스트
```

## 데모 모드 경계

**본 서비스는 데모(시연)입니다. 특히:**

- **모든 상품·가격·영양수치·리뷰는 가상**이며 예시용입니다.
- **결제·구독은 모의**입니다 — 실제 청구·주문·배송이 없습니다.
- **상태는 브라우저 `localStorage`에만 저장**되며 실제 DB가 아닙니다. 기기별로만 유지되고 언제든
  지워질 수 있으며 "데모 초기화" 버튼으로 리셋됩니다.
- **계정·로그인·개인정보(PII) 수집/전송 없음.**
- **연화 단계·영양 목표·추천은 의료/영양 처방이 아닙니다.**
- 실제 제품이라면 백엔드·실 DB, 인증된 실 카탈로그·재고, 실 결제 게이트웨이, 실 물류, 그리고
  전문 자격자가 검수·승인한 영양/연하 정보가 추가되어야 합니다.
